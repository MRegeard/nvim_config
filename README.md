# My Neovim configuration

**Prerequisite:** Requires [ripgrep](https://github.com/BurntSushi/ripgrep).

## Description of the plugin:

- [autoclose.nvim](https://github.com/m4xshen/autoclose.nvim) -- Autoclose "pair" symbols (e.g. `""`, `()`)
- [cellular-automaton.nvim](https://github.com/Eandrju/cellular-automaton.nvim) -- Cellular Automaton
- [cloak.nvim](https://github.com/laytan/cloak.nvim) -- Display `*` on specific patterns (e.g. password or private variable)
- [conform.nvim](https://github.com/stevearc/conform.nvim) -- Formatting
- [fugitive.nvim](https://github.com/tpope/vim-fugitive) -- Git plugin
- [harpoon](https://github.com/ThePrimeagen/harpoon/tree/harpoon2) -- Switch between buffer
- [nvim-lightbulb](https://github.com/kosayoda/nvim-lightbulb) -- VSCode 💡 for Neovim
- [lualine.nvim](https://github.com/nvim-lualine/lualine.nvim) -- Status bar
- [LuaSnip](https://github.com/L3MON4D3/LuaSnip) -- Code snippets
- [markdown-preview.nvim](https://github.com/iamcco/markdown-preview.nvim) -- Markdown preview in web browser
- [nvim-navic](https://github.com/SmiteshP/nvim-navic) -- Code context in the status bar
- [telescope.nvim](https://github.com/nvim-telescope/telescope.nvim) -- Fuzzy finder
- [tree-sitter-manager.nvim](https://github.com/romus204/tree-sitter-manager.nvim) -- Tree-sitter manager for neovim 0.12
- [trouble.nvim](https://github.com/folke/trouble.nvim) -- Diagnostics, references, quickfix, etc.
- [undotree](https://github.com/mbbill/undotree) -- Undo tree
- [zen-mode.nvim](https://github.com/folke/zen-mode.nvim) -- Distraction free coding

### LSP

- [nvim-lspconfig](https://github.com/neovim/nvim-lspconfig) -- LSP server configuration
- [mason.nvim](https://github.com/mason-org/mason.nvim) -- LSP server manager
